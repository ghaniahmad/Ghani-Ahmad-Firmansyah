# Ghani Ahmad Firmansyah — Personal Portfolio

Website portofolio untuk project UTS Pemrograman Berbasis Web Lanjut.

## File
- `index.html` — struktur dan isi website
- `style.css` — desain colorful dan responsif
- `script.js` — menu mobile, tombol sapaan, filter proyek, dan validasi formulir
- `profile-ghani.jpg` — foto profil

## Menjalankan
Ekstrak ZIP, lalu buka `index.html` di browser. Semua file di atas harus berada di folder yang sama. Internet diperlukan untuk memuat font eksternal.

## Hosting GitHub Pages
1. Buat repository publik di GitHub.
2. Upload seluruh file ke root repository.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Tunggu deployment selesai dan buka URL yang disediakan GitHub Pages.

Alternatif: unggah folder project ke Netlify.

## Catatan isi
Informasi pendidikan, keterampilan komputer, pengalaman volunteer, dan bahasa diadaptasi dari CV yang diberikan. Proyek di bagian portofolio tetap diberi label sebagai contoh/latihan dan perlu disesuaikan dengan karya nyata. Formulir kontak hanya memvalidasi data di browser; belum mengirim pesan ke server.
